# Manga desk user guide

Manga desk is a desktop app for macOS and Windows. It downloads chapters from websites you set up, turns them into comic archives (`.cbz` files) and copies them to a reader app on your iPhone over a cable.

Manga desk ships no manga, no list of websites and no catalog. You add the sources, and you decide what to download. Only use it for material you have the right to copy.

## Get help

Look in [Troubleshooting](./troubleshooting.md) first. To report a problem, open an issue in the releases repository: `https://github.com/Jonathan-Nuno/manga-desk`. Use Settings › About › Copy diagnostics and paste the result into your report. Do not paste website addresses or anything else you want to keep private.
